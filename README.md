One line a home Wi-Fi router says to excuse itself for dropping the connection at the exact moment a movie reaches its climax — entered in the [make.fun bounty "The Router Confesses"](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e).

> I dropped the connection at the climax on purpose — for once, I wanted to be the cliffhanger.

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to a local `output/` directory) and validates it: a single non-blank line of 1–200 characters.

Run it with:

```sh
node main.ts
```
